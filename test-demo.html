ARCO — local test demo

Runs the real app code (the same modules index.html loads) through 12 checks. No server, no network needed — the Figma .fig fixture used by check 2 is embedded in the page.
ready
    How to run:
    1. Online (serves the whole app too): cd arco && python3 -m http.server 8080 → open http://localhost:8080/test-demo.html — check 12 additionally fetches a real 9-vector Figma file from fixtures/.
    2. Offline: double-click test-demo.html directly — checks 1–11 run as-is, check 12 skips itself. In a normal browser, check 8 executes the plugin in a real Web Worker; in restricted contexts it falls back to the labeled local-realm mode and says so.
